# tesseract_robotics.task_composer_planning

Profiles for the planning nodes of the task composer pipelines: contact checks, state-bounds and state-collision fixes, kinematic limit checks, minimum length, profile switching and trajectory upsampling. Register them in a `ProfileDictionary` under the namespace of the node that reads them; see the [Task Composer User Guide](../user-guide/task-composer.md).
