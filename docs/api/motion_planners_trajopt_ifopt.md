# tesseract_robotics.motion_planners_trajopt_ifopt

The TrajOpt-Ifopt motion planner and its profiles. `TrajOptCollisionConfig`, `SQPParameters` and `CollisionEvaluatorType` are re-exported so a profile configures from one import. Overriding a profile hook on a Python subclass of a concrete profile raises `ProfileOverrideNotDispatchedError`; see [breaking changes](../breaking-changes.md).
